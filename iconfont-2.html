SVG vs. Font.
Two worlds.

APPROACH

Lucide — SVG

每一个图标都是原生的 SVG 节点 —— 可以直接填充颜色、调整 stroke-width、 甚至用 CSS 动画 path。没有字体加载闪烁，没有跨平台渲染差异。

  • 矢量无损缩放
  • 可逐路径动画
  • 零字体依赖
  • Tree-shakable

Font Awesome — Font

用 @font-face 把图标做成字体字形 —— 一行 class 即可调用， 适合文字流内联，但受到字体渲染和字符映射的约束。

  • CSS class 即用
  • 文字流内联友好
  • 多 weight 风格
  • Brand logos 齐全
