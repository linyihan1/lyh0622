🎤 答辩四连问（上台能背）

transform 里的百分比相对谁的？ → 相对当前 slide 自身的宽度，translateX: '100%' = 右移一个 slide 宽
改 rotate 的 Z 为 20 度试试？ → rotate: [0, 0, 20] 三个值分别是 [X Y Z]，Z 是平面内旋转
prev / next 各控制什么？ → prev 控制上一张"退场长什么样"，next 控制下一张"进场长什么样"，两者同时叠在一起过渡
为什么叫"电影墙"？ → 上一张缩小左移像从银幕滚走，下一张放大右移像新镜头推上银幕

为什么要点一下？ Swiper 11 的 keyboard 模块默认要先点容器才激活——这是无障碍设计，防止页面一加载焦点被抢走，不是 bug 是特性。

🧩 超纲能力：keyboard 键盘控制

new Swiper('#lyh_t3_swiper', {
  loop: true,
  keyboard: true,   // ← 超纲参数，课堂没讲过
  pagination: { el: '#lyh_t3_pag', clickable: true },
  navigation: { nextEl: '.swiper-button-next', prevEl: '.swiper-button-prev' },
});

🎤 答辩四连问（上台能背）

keyboard: true 什么意思？ → 开启 Swiper 的 keyboard 模块，监听 ← → Home End 四个键控制翻页
为什么要先点一下才能用？ → 这是 focus 机制，浏览器需要 DOM 元素获得焦点后才能接收键盘事件，防止干扰页面其他输入框
AI 第一次给的哪里不对？ → AI 推荐过 zoom（双击缩放），但实际不生效要额外配置；换成 keyboard 一行代码就搞定
爱达·魔都号是什么？ → 中国首艘国产大型邮轮，2024 年 1 月 1 日从上海首航
